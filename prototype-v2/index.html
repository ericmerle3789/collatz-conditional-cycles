Suppose a non-trivial odd Collatz cycle.Set odd length k and total even-exponent sum S.
Use the formal cycle equation.Move from dynamics to arithmetic constraints on powers of 2 and 3.
Apply the product/minimum bound chain.Bound the minimal cycle element through formalized inequalities.
Split into small and large k.For k ≤ threshold, the bound drops below the verification range.
Use BarinaVerification below 2^71.A cycle element below that range reaches one, contradicting cyclicity.
For large k, invoke DerivedLargeKBound.The bridge again brings the cycle element below 2^71.
Contradiction.Under the external hypotheses, no non-trivial cycle remains.
Scope boundary.This closes the no-cycle conditional branch, not full unconditional convergence.

4 · Read the paper

Compare theorem statement, Lean theorem, and website claims line by line.

5 · Open an issue

Use GitHub for red-team findings, especially on hypothesis status and naming.
